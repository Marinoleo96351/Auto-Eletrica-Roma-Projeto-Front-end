# Auto Elétrica ROMA — Projeto Front-end

Projeto prático da disciplina **Programação Web Front-end** do 4º período de Engenharia de Software.

---

## Descrição do Projeto

O projeto consiste no desenvolvimento de uma aplicação web para a **Auto Elétrica ROMA**, um pequeno comércio local especializado em elétrica automotiva e ar condicionado.

O objetivo do website é resolver um problema direto da comunidade: a dificuldade e a demora na solicitação de orçamentos e socorros elétricos automotivos. A página centraliza o contato, permitindo que os clientes solicitem assistência e agendem diagnósticos de forma rápida, reduzindo o tempo que veículos (de trabalhadores e frotistas) ficam parados.

---

## Estrutura do Projeto

```
Auto-Eletrica-Roma-Projeto-Front-end/
│
├── index.html       # Página principal com apresentação, serviços, galeria e contato
├── cadastro.html    # Página de agendamento de diagnóstico (formulário com 7 campos)
├── login.html       # Página de login, destino após envio do formulário de cadastro
├── style.css        # Folha de estilos global (todas as páginas)
│
└── README.md        # Documentação do projeto
```

### Páginas

| Página | Descrição |
|---|---|
| `index.html` | Página principal com cabeçalho, navegação, seção hero, serviços, galeria, contato e rodapé |
| `cadastro.html` | Portal de agendamento de diagnóstico com formulário de 7 campos |
| `login.html` | Página de acesso à conta, exibida após o envio do agendamento |

### Tecnologias Utilizadas

- **HTML5** — estrutura semântica com tags `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`
- **CSS3** — estilização completa sem frameworks, com variáveis de cor, Flexbox e Grid Layout
- **Google Fonts** — tipografias Oswald (títulos) e Roboto (corpo)
